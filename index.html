Version control, explained

GitHub helps people build software together.

GitHub is a platform for hosting code, tracking changes, and collaborating on projects with people anywhere in the world.

How do you use GitHub?

Start by creating an account and a repository—a home for your project files. You can make changes locally with Git or edit files in the browser, then commit your work with a clear message. Push changes to GitHub, open pull requests for review, and merge approved work into the project.

✦

Track every change

Git records the history of a project, making it easy to compare versions, understand what changed, and safely restore earlier work when needed.

▧

Collaborate clearly

Branches and pull requests let teammates work independently, review changes, leave feedback, and combine work with confidence.

⌁

Share your work

Repositories make it simple to share projects, contribute to open source, document your work, and build a visible portfolio.

✓
Build good GitHub habits

Commit small, focused changes; write meaningful commit messages; use a .gitignore file for generated files; and never commit passwords, API keys, or other sensitive information.
